Save login for tests

The file holds this browser’s cookies for the site, httpOnly ones included, and the site’s localStorage, in Playwright’s storageState format. IndexedDB is left out.

Anyone with this file is logged in as you until the session expires. Use a test account, and keep the file out of your repository.

Save it as playwright/.auth/user.json and add playwright/.auth to .gitignore.

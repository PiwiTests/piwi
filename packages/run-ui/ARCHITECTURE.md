# Run UI layer architecture

What the Nuxt layer in `packages/run-ui/` holds. The rules are in [`AGENTS.md`](AGENTS.md). This file is reference
material: open it when you need to understand the code.

## What it holds

| Path                                                                                                  | What                                                                                                                                                                                                 |
| ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app/components/DesktopTeamRunRequestModal.vue`                                                       | The confirmation of a run request a team instance sent; emits `start` when **Run** wins                                                                                                              |
| `app/components/DesktopTeamInstance.vue`                                                              | Connecting to a team instance (the device flow), its status, its linked folders (`folders: false` leaves them out); `appName` names the app                                                          |
| `app/components/DesktopTeamConnectForm.vue`, `DesktopTeamSignIn.vue`, `DesktopTeamFolders.vue`        | The card's parts each host's views share: the address and Connect, the sign-in's code, the linked folders and Unlink                                                                                 |
| `app/components/CodeBlock.vue`                                                                        | A code block with a copy button                                                                                                                                                                      |
| `app/composables/useDesktopTeamRequests.ts`                                                           | The connection and the queue of requests the confirmation shows                                                                                                                                      |
| `app/composables/useDesktopTeamConnection.ts`                                                         | What a view of the connection does: connect, disconnect (not while the key is being kept), the linked folders and Unlink                                                                             |
| `app/composables/useTauri.ts`, `useCopy.ts`                                                           | The Tauri bridge (`tauriCore`, `tauriEvent`, `tauriWindowLabel`) and the clipboard                                                                                                                   |
| `app/utils/run-target-words.ts`, `text.ts`                                                            | The words of the connection and the request, `errorMessage`, `copyPreview` (`@piwitests/run-ui/text`)                                                                                                |
| `app/utils/desktop-events.ts`                                                                         | The one shared `EventSource` on `/api/desktop/events` (`subscribeDesktopEvents`)                                                                                                                     |
| `app/plugins/desktop-team-requests.client.ts`                                                         | Feeds the host's run-request queue from that stream inside the shell's main window                                                                                                                   |
| `src/highlight.ts` (`@piwitests/run-ui/highlight`)                                                    | The one syntax-highlighting setup, also used by the server's exports and notifications                                                                                                               |
| `app/composables/useDesktopRunHub.ts`                                                                 | The window's side of the runs' hub: the stream of `/api/desktop/runs/events` and the commands                                                                                                        |
| `app/components/DesktopRun*.vue`                                                                      | The live view of a run: its workers (`DesktopRunSession`, `DesktopRunWorker`), a stop's and a lane's page, the code to copy                                                                          |
| `app/components/DesktopRunStopButton.vue`, `app/utils/run-stop.ts`                                    | A run's Stop, then Force stop while it winds down, guarded a moment after Stop, beside the seconds the shell's grace leaves                                                                          |
| `app/components/DesktopRunOutputPane.vue`, `app/utils/run-output.ts` (`@piwitests/run-ui/run-output`) | A run's output: the line model both hosts keep (`runOutputLine`), its colors, filter, first error, wrap and Copy output; what Playwright's end-of-run summary says of each test (`runOutputSummary`) |
| `app/components/DesktopRunResults.vue`                                                                | A finished run's tests and how each came out (`RunResultRow`), its first error lines and place, each host adding its links and actions                                                               |
| `app/components/DesktopRunsPanel.vue`                                                                 | A window's runs beside the run shown: the groups' lines (how each run stands, a stop waiting, how long it ran), a select instead when narrow, the host drawing the run shown                         |
| `app/utils/run-view.ts` (`@piwitests/run-ui/run-view`)                                                | The live view's pure half: keys, the run model's English words and icons, Share live, the items to copy                                                                                              |
| `app/utils/run-view-host.ts`                                                                          | What a host adds to the live view (`RUN_VIEW_HOST`): a worker's own window, the link to a stop's file, a lane's Inspect                                                                              |
| `app/components/ErrorText.vue`, `LocatorCode.vue`                                                     | An error with its ANSI colors (`@piwitests/run-ui/ansi`), a locator highlighted                                                                                                                      |
| `app/utils/status-palette.ts`, `ui-classes.ts`                                                        | The outcome colors (`STATUS_PALETTE`) and the neutral classes the shared marks and the selected row take                                                                                             |
| `src/fold-text.ts` (`@piwitests/run-ui/fold-text`)                                                    | The search fold every list compares with, accents and case ignored                                                                                                                                   |
| `app/assets/css/run-ui.css` (`@piwitests/run-ui/run-ui.css`)                                          | The outcome tokens (`--color-status-*`) and the highlight.js theme, imported by each host's Tailwind entry                                                                                           |
| `app/plugins/desktop-external-links.client.ts`                                                        | Opens a cross-origin link in the default browser inside a shell's window (`desktop_open_external`)                                                                                                   |
| `locales/<code>.json`, `app/utils/run-ui-words.ts`                                                    | The layer's catalogs, in Piwi Picker's shape, and how they are read (`runUiTranslator`, `RUN_UI_WORDS`, English by default)                                                                          |
| `app/composables/useRunUiWords.ts`, `RunUiText.vue`                                                   | The words a host provides, else English; a message whose placeholders hold markup                                                                                                                    |
